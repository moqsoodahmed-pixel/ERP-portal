# Vendor / data-processor management

Register processors in `DataProcessor` (name, purpose, data categories, country, contract reference, status). Examples to assess: hosting/DB provider, object storage, email/SMS provider, Tally connector, GST ASP/GSP, monitoring.
Checklist per processor: purpose and data minimisation; contract with security and breach-notice terms; sub-processors; location/transfer considerations `[Legal]`; access method (least privilege, no shared credentials); exit/deletion terms; review cadence.
GST vendors are *platform users* with scoped access (assignment-based, audited); their organisational obligations belong in their contract `[Legal]`.
